PASS if all of these hold: the title is a question ending with "?"; there is exactly one answer line, a single declarative sentence; there are exactly three labels, each starting with "The" and naming a thing, each followed by one to three short lines in the present tense; there are no exclamation marks.
FAIL if any of them is missing or broken, for example a title that is not a question, more than one answer line, a label that does not start with "The", or an exclamation mark.
